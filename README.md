# 🌱 Growth Mindset Challenge – Streamlit App

This is a simple yet effective Streamlit web application that encourages users to develop a growth mindset. Each time you click the button, a new motivational challenge is presented to inspire personal growth, learning, and positivity.

## 💻 How to Run Locally

```bash
streamlit run mindset_app.py
```
## 🚀 Features
- 🎯 Randomized growth mindset prompts
- 🌿 Clean and minimal UI
- ⚙️ Built using Python and Streamlit
